500 лучших фильмов.

Проблема: создать сайт, который динамично отображает 500 фильмов из базы с категориями, где пользователи могут оставлять отзывы.

Пользователи: обычные посетители (только чтение), зарегистрированные пользователи (могут оставлять комментарии), администраторы (полное управление сайтом, управление бд), модераторы (доступ к удалению отзывов).

Требования функциональные:
Пользователи должны иметь возможность оставлять комментарии, отзывы.
Все пользователи должны иметь возможность искать фильмы из базы данных.
Данные о фильмах должны подгружаться на фронт-енд из базы данных. При прокрутке – динамически.
Администраторы должны иметь возможность добавить новые данные в базу данных.
Оставленные комментарии и отзывы должны отображаться под фильмами, рейтинг должен отображаться суммарно из всех оценок пользователей.
Информация о фильме должна включать – название, год, описание, кем сделан, рейтинг на сайте, рейтинг на других сайтах.


Нефункциональные требования:
Защита от sql-инъекций.
Система ищет быстро.
Оставить отзыв можно в 2 клика.
Интерфейс: меню, войти/регистрация, после входа отображается имя пользователя, на главной отображаются фильмы по страницам, на странице фильма отображается информация о фильме и отзывы.

Ограничения:
Работа через интернет.
Хранение данных в базе.
Оставить отзыв можно только после авторизации.
Без авторизации – только чтение.
Модераторам доступно только изменение отзывов.


Архитектура:

Таблица отзывов.
Таблица пользователей с ролями.
Таблица фильмов.
